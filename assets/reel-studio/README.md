# Reel asset studio

Open `../assets.html` from the portfolio source to make an Instagram Reel cover or end card, or a LinkedIn portrait, landscape, or square card. Edit title and supporting details, pick a pose, save a named setup in this browser, and download a PNG.

The card art is built from the approved creature source and existing authored 2D frames in `docs/projects/portfolio-character/hero-poses-v1/`. No generated dragon art is used. The small pose references come from `blender-production-v1/character-rig-v2/lucy-creature-rig-v2.1.blend`; they guide posture and contact only. The 3D render is never exported as the character artwork.

Local card setups are stored in browser localStorage (`ll.reelStudio.*`). The project files themselves remain editable and self-contained.
