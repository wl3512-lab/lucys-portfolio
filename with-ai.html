Today

Featured build · Today

One place to start my day.

A planner I designed for my own day. It brings class assignments, my inbox, and Google Calendar into one place.

01 / Find the assignment

Assignments come from Brightspace, spreadsheets, websites, and Discord. Today gathers them every two hours and keeps each source attached.

02 / Make time for it

I drag an assignment into a free hour. Today adds the study block to my Google Calendar, beside the events already there.

03 / Start with context

The study helper opens with the assignment brief and materials. It can access that assignment only, keeping the rest of my planner private.

This site · Design + code

How I made this site.

I direct the design, test it with people and build it with AI. The creature who lives in it has his own process.

Built, tested and checked

Plain HTML and React, precompiled and deployed with one script. User testing cut the home page down, a design audit cut 126 styles to 50, and 44 test files with more than 580 checks run before each release.

A rig that kept the drawings accurate

I used a Blender rig as a guide so AI drawings did not invent extra blades or wrong limbs, but I did not ship Blender renders. The animations are 2D pixel frames.
