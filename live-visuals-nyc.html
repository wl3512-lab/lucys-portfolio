How it works

every Thursday i build the visuals from scratch in TouchDesigner and run them live across the full ceiling above the dance floor. they react to frequency bands, percussive hits, and how hard the room is going. i wrote and operate the whole network myself. TouchDesigner reads a live audio device feed and splits it into frequency bands: kick, low, mid, and high. each band drives a different visual parameter. every song hits differently, though; some tracks have a soft kick, others compress the highs, some run loud all night. so through the set i tune the detection thresholds by hand in real time, raising the kick floor so a quiet track still triggers geometry, pulling back the mid sensitivity when a dense mix starts firing everything at once. if the audio isn't being read cleanly, the visuals fall apart, so that calibration never stops.
