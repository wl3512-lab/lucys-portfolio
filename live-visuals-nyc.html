How it works

Diablo + friends

Every Thursday I build the visuals from scratch in TouchDesigner and run them live across the full ceiling above the dance floor. They react to frequency bands, percussive hits, and how hard the room is going. I wrote and operate the whole network myself.

Read more

TouchDesigner reads a live audio device feed and splits it into frequency bands: kick, low, mid, and high. Each band drives a different visual parameter. Every song hits differently, though; some tracks have a soft kick, others compress the highs, some run loud all night. So through the set I tune the detection thresholds by hand in real time, raising the kick floor so a quiet track still triggers geometry, pulling back the mid sensitivity when a dense mix starts firing everything at once. If the audio isn't being read cleanly, the visuals fall apart, so that calibration never stops.
